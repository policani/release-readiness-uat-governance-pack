# Working Session Prompts

Use these prompts inside the ChatGPT Project.

## Start intake

Start a release readiness review. Use the intake file first. Extract what I already provided, identify material gaps, and ask no more than 10 questions grouped by scope, evidence, environment/data, defects, and signoff.

## Build UAT gates

Using this release context, draft UAT entry and exit criteria. Make each criterion observable, evidence-based, and tied to an accountable owner or signoff area.

## Screen evidence

Review this test evidence and defect summary. Identify evidence gaps, weak assertions, stale status, coverage concerns, blocker risks, and questions that must be resolved before UAT exit.

## Review environment and data readiness

Assess environment, access, integration, batch, and data readiness from the following notes. Separate blockers from manageable risks and produce an escalation-ready table.

## Build signoff matrix

Create a signoff matrix for this release. Include business, QA, technology, environment/data, operations/support, finance/accounting if applicable, security/privacy/compliance if applicable, and sponsor decision ownership.

## Prepare launch decision brief

Build a launch decision brief for sponsor review. Include readiness scores, blockers, launch conditions, risks of proceeding, risks of holding, decisions required, and downstream handoffs.

## Quality review

Review this readiness pack for weaknesses. Flag missing evidence, overclaiming, vague ownership, unsupported recommendations, hidden decision rights, and any language that sounds like AI is approving the launch.
