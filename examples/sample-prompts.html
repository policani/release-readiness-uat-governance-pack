Sample Prompts

Synthetic prompt set

Use these prompts after uploading only the contents of chatgpt-project/ into a ChatGPT Project.

1. Start readiness intake

Start a readiness review for a finance-impacting system release. Use the intake file first. Extract known facts, identify material gaps, and ask no more than 10 questions grouped by scope/date, evidence, environment/data, defects, and signoff.

Scenario:
[Paste release profile, workstreams, test status, defects, environment notes, and signoff context.]

2. Build UAT entry and exit criteria

Using the confirmed release context, draft UAT entry and exit criteria. Make each criterion observable, evidence-based, and tied to an accountable owner or signoff area. Separate must-have criteria from launch-condition candidates.

3. Review evidence readiness

Review this test and defect evidence. Score evidence readiness 0-3 by dimension, identify weak or missing evidence, and list the minimum proof needed before UAT exit or launch decision review.

4. Review environment and data readiness

Assess environment, access, integration, batch, and data readiness. Separate blockers from material risks and action items. Produce an escalation-ready table with owner, due date, gate impact, and decision needed.

5. Build signoff matrix

Create the signoff matrix for this release. Include business, QA, technology, environment/data, operations/support, finance/accounting, and sponsor decision ownership. Flag where approval is implied, missing, informal, or unsupported.

6. Prepare launch decision brief

Build a launch decision brief for sponsor review. Include readiness scores, blockers, launch conditions, risks of proceeding, risks of holding, human decisions required, and downstream handoffs to the executive portfolio review, PMO governance log, and value realization ledger.

7. Quality review

Review this readiness pack for weaknesses. Flag missing evidence, overclaiming, vague ownership, hidden decision rights, unsupported recommendations, and any language that sounds like the AI is approving launch.
